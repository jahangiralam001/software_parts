About This Project

A memorization-friendly way to learn Linux directories with practical context.

Visualizer About

Learning goal

This site is built for retention. Each directory is explained through seven repeating questions so your brain always sees the same learning pattern.

  1. What is this directory?
  2. Why does Linux need it?
  3. Real files inside it
  4. Commands to explore it
  5. What happens if you delete it?
  6. Difference from similar directory
  7. Modern Linux changes

How to use

  • Start on the Visualizer page and click one directory at a time.
  • Run commands in a VM or container, not your main system.
  • Open direct pages from pages/ when revising one directory only.
