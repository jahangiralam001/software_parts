# Chat App

A basic real-time chat app built with Node.js, Express, and Socket.IO.

## Live Demo
https://chat-app-ox9k.onrender.com/

## Features
- Real-time message exchange between two browser clients
- Typing indicator support
- Read receipt event support

## Tech Stack
- Node.js
- Express
- Socket.IO

## Run Locally
1. `npm install`
2. `node server.js`
3. Open `http://localhost:3000`
